# Data

`airports.dat` is the airport database of **OpenFlights.org**
(https://openflights.org/data.php; GitHub repository `jpatokal/openflights`). This copy is the
version posted on the EECE 2560 course page, so that every student works with the same data.

- 7,698 lines, one airport per line, 14 comma-separated fields
- SHA-256: `9387cdb38df5bd664da823f8ccb69fdd9b33a1888f5b7cca09c34a3cd9ff59f9`
- The file is unchanged.
